# Configure a Custom Domain

This guide is an intentionally stale fixture for the GuideSync MVP.

## Before You Start

- You need workspace admin access.
- You need access to your DNS provider.

## Steps

1. Open the solution settings.
2. Find the public URL field.
3. Enter your custom domain.
4. Save the setting.
5. Update your DNS records.

## Notes

- This old guide assumes custom domains are configured directly inside solution settings.
- It does not mention workspace-level domain inventory, TXT verification, A routing records, binding status, service binding or artifact binding.
